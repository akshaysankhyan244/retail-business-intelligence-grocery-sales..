# Retail Business Intelligence System for Grocery Sales Analysis

## About the Project

This project focuses on analyzing grocery sales data to understand sales performance, product trends, and outlet performance. The main goal is to turn raw sales data into useful insights that can help businesses make better decisions.

I worked on data cleaning, data analysis, SQL queries, and dashboard development using Python, MySQL, and Power BI.

## Tools & Technologies

- Python
- Pandas
- Matplotlib
- MySQL
- Power BI
- Jupyter Notebook

## Project Workflow

1. Collected and explored the grocery sales dataset.
2. Cleaned the data and handled missing values.
3. Analyzed sales data using Python and Pandas.
4. Used MySQL to perform queries and examine business performance.
5. Created visualizations to understand sales trends.
6. Developed a Power BI dashboard to present key metrics and insights.

## Key Metrics

- Total Sales: 1,201,681.49
- Average Sales: 140.99
- Average Rating: 3.97
- Total Products: 1,559
- Total Outlets: 10

## Analysis Performed

- Sales by item type
- Sales by outlet type
- Sales by outlet size
- Sales by item fat content
- Comparison of outlet performance
- Analysis of important business KPIs

## How to Use This Project

1. Clone or download this repository.
2. Install Python and the required libraries.
3. Open the Jupyter Notebook.
4. Load the cleaned grocery sales dataset.
5. Run the analysis cells to explore sales performance.
6. Import the dataset into MySQL to execute SQL queries.
7. Open the Power BI dashboard in Power BI Desktop, if the .pbix file is included.
